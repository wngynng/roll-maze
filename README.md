# 滚球迷迷宫 · Roll Maze

倾斜手机（或用键盘）滚小球走迷宫的 H5 休闲游戏——收集星星，抵达绿色终点。

**50 关 · 10 大机制区**：回廊 → 黑洞 → 冰原 → 深渊迷雾 → 巡逻块 → 弹射带 → 传送门 → 崩塌地板 → 定时闸门 → 终局全机制混合。

## 直接开玩

👉 打开本页面的 GitHub Pages 链接（即仓库地址里的 `https://<用户名>.github.io/roll-maze/`）。

- **手机**：点「开始游戏」并允许动作与方向权限（iOS 需要 HTTPS，GitHub Pages 已原生提供），倾斜手机控制；进关自动校准姿态，躺着玩也没问题
- **无传感器 / 桌面**：触屏浮动摇杆（按下处即原点）或 方向键 / WASD

## 特色

- **零依赖单文件**：整个游戏是一个 `index.html`（Canvas 自绘渲染 + 自写物理：加速度 / 阻尼 / 圆 vs 网格碰撞 / 恢复系数）
- **确定性关卡生成**：种子化生成器 + 三重静态校验（BFS 可达性 / 星星双保险 / 巡逻封路检测），全 50 关 CLI 自动验证通过
- **宽恕设计**：掉洞回检查点（星星不丢）、终点磁吸、巡逻块撞飞不致死、闸门防压死
- **传感器自适应**：deviceorientation 主链路 + devicemotion 重力矢量备用链路，单轴失效 3 秒内自动切换；⚙ 面板可诊断与一键修正轴向
- **手感调参**：输入曲线（死区 3° → 指数 2.2 → 满偏 40°）与物理参数集中在源码 `PHYS` 段，真机体感可一键复调

## 通关小抄

| 机制 | 提示 |
|---|---|
| 冰原 | 提前很久就反向倾斜，冰上真的刹不住 |
| 迷雾 | 检查点会闪现照明 2.4 秒，借光探路 |
| 巡逻块 | 被撞飞不会死，但可能把你带进洞 |
| 弹射带 | 只能顺箭头方向，逆着必被推回 |
| 崩塌 | 踩过的地板会碎，回头路是自杀不是死路 |
| 闸门 | 琥珀色门定时开合，卡节奏穿行 |
